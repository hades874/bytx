# bytx — বাংলায় দ্রুত শুরু

bytx একটি ফ্রি, ওপেন-সোর্স টুল। এটি বাংলা ও ইংরেজি ইউটিউব আর ফেসবুক ভিডিওর
কথা লেখায় (ট্রান্সক্রিপ্ট) রূপান্তর করে আপনার নিজের কম্পিউটারেই, আর সেগুলো
একটি খোঁজা যায় এমন লাইব্রেরিতে রাখে। কোনো পেইড সার্ভিস লাগে না, আপনার কোনো
ডেটা কম্পিউটারের বাইরে যায় না।

## ইনস্টল

১. [uv](https://docs.astral.sh/uv/getting-started/installation/) ইনস্টল করুন। উইন্ডোজে PowerShell খুলে:

```
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

২. bytx ইনস্টল করুন (নতুন টার্মিনাল খুলে):

```
uv tool install bytx              # যেকোনো কম্পিউটারে; CPU-তে চলে
uv tool install "bytx[gpu]"       # NVIDIA GPU থাকলে (উইন্ডোজ বা লিনাক্স); প্রায় ১.৩ GB বেশি ডাউনলোড
```

৩. স্পিচ মডেল নামান আর সব ঠিক আছে কিনা দেখুন:

```
bytx setup      # বাংলা (প্রায় ১.৫ GB) আর ইংরেজি (প্রায় ১.৬ GB) মডেল, একবারই
bytx doctor
```

Python, ffmpeg বা Deno আলাদা করে ইনস্টল করতে হবে না।

## প্রথম ট্রান্সক্রিপ্ট

```
bytx add "https://www.youtube.com/watch?v=XXXXXXXXXXX" --lang bn --run
```

- **`--lang` সবসময় দিন:** বাংলা ভিডিওর জন্য `bn`, ইংরেজির জন্য `en`। ইংরেজি
  শব্দ মেশানো বাংলা কথাও `bn`। ভুল ভাষা দিলে লেখা অর্থহীন হয়: ইংরেজি ভিডিওকে
  `bn` দিলে বাংলা অক্ষরে আবোল-তাবোল আসে, আর কোনো সতর্কবার্তাও আসে না।
- ভাষা নিশ্চিত না হলে `--lang auto` দিন।

তারপর:

```
bytx list                           # লাইব্রেরির সব ভিডিও
bytx show <video_id>                # ট্রান্সক্রিপ্ট পড়ুন
bytx search "বাংলাদেশ"              # শব্দ দিয়ে খুঁজুন
bytx export <video_id> --format srt --output out.srt
bytx quality                        # কোন ট্রান্সক্রিপ্ট আবার দেখে নেওয়া উচিত
```

ভুল ভাষায় দিয়ে ফেললে আগে মুছে ফেলুন, তারপর সঠিক `--lang` দিয়ে আবার দিন:

```
bytx remove <video_id> --yes
bytx add "<url>" --lang en --run
```

## ফাইল কোথায় থাকে

সবকিছু `~/bytx` ফোল্ডারে থাকে (উইন্ডোজে `C:\Users\<আপনার নাম>\bytx`)।
পড়ার মতো কপিগুলো `yt-transcribed-files/` ফোল্ডারে। অন্য কোথাও রাখতে চাইলে
`BYTX_HOME` এনভায়রনমেন্ট ভ্যারিয়েবলে সেই ফোল্ডারের পথ দিন।

## কত সময় লাগে

NVIDIA GPU থাকলে ভিডিওর দৈর্ঘ্যের চেয়ে অনেক কম সময় লাগে। শুধু CPU-তে
৬-কোর ডেস্কটপে ভিডিওর দৈর্ঘ্যের প্রায় ২.২৫ গুণ সময় লাগে, ল্যাপটপে আরও বেশি:
৩০ মিনিটের ভিডিওতে এক ঘণ্টার বেশিও লাগতে পারে।

## প্রশ্নোত্তর আর সারাংশ (ঐচ্ছিক)

অর্থ দিয়ে খোঁজা (`bytx search ... --semantic`), প্রশ্ন করা (`bytx ask`) আর
সারাংশের জন্য [Ollama](https://ollama.com) লাগে, আর তার মডেল প্রায় ৫ GB।
Ollama ছাড়াও ট্রান্সক্রিপ্ট, শব্দ দিয়ে খোঁজা আর এক্সপোর্ট পুরোপুরি কাজ করে।
পরে Ollama ইনস্টল করলে `bytx setup`, তারপর `bytx run` চালান।

## দায়িত্বশীল ব্যবহার

শুধু সেই ভিডিও ট্রান্সক্রাইব করুন যেগুলো ব্যবহারের অধিকার আপনার আছে। কপিরাইট
এবং ইউটিউব ও ফেসবুকের নিয়ম মেনে চলুন, আর অনুমতি ছাড়া অন্যের কথা প্রকাশ করবেন না।
